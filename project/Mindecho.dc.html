Context & assumptions

Source. The Mindecho repo is empty, so everything here is built from the product doc. Modernist system applied: Archivo, red on off-white, 2px rules, zero radius, flush-left labels.

Language. UI chrome in English, captured content in Korean (doc examples: JoaSuite, Liflux, David, 로마서 8장).

System. One type ramp per screen: uppercase 10px kicker → 28px Archivo 800 title → 15px body. Entry types are red kickers (IDEA / TASK / DECISION), topics are neutral tags. Every AI summary carries a "Source →" link back to the original conversation. Mic is the only accent-filled block on Home.

Nav. Home / Calendar / Tasks / Memory / Search / Account. Recording starts from Home; Topics, Journal and Threads live under Memory.

Prototype (1a). Tap the mic to record; stop → post-capture summary. Inbox review resolves inline, tasks toggle, Ask My Memory sources open the Idea Thread. Driving Mode from Home.
